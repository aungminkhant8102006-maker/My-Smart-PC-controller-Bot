# 🖥️ My Smart PC Controller Bot

A Python-based Telegram bot designed to remotely control and manage my personal computer directly from Telegram. 

## ✨ Key Features
* **Remote Management:** Easily control PC functions via Telegram commands.
* **Background Execution:** Utilizes `.pyw` and `.bat` files for seamless, windowless background operation.
* **Secure Access:** Configured to respond only to authorized user IDs.

## 🛠️ Technologies Used
* Python
* Telegram Bot API
* Windows Batch Scripting

> **Note:** API keys and sensitive tokens have been removed from this public repository for security purposes.
